# SÄKRA Public SDK & Libraries

This repository contains the public-facing client SDKs and verification libraries for the SÄKRA cryptographic governance protocol.

- `@sakra/sdk`: The developer SDK.
- `@sakra/verify`: The cryptographic verifier (zero runtime dependencies).
- `@sakra/mcp-sdk`: Model Context Protocol integration.
- `@sakra/mcp-proxy`: MCP CLI proxy.
